# ⚡ منظومة كتاب دياجنوستكس (Ktaab Smartphone & Deep Battery Diagnostics)

مشروع متكامل ومتقدم لفحص الهواتف الذكية وصحة البطارية بدقة برمجية متناهية، يتكون من **تطبيق هاتف (Flutter App)** يدعم اللغة العربية بالكامل والوضع الليلي، متصل بـ **سيرفر خلفي ولوحة تحكم تفاعلية (Node.js + Express + SQLite)**.

---

## 🌟 الميزات الرئيسية للمنظومة

### 1. تطبيق الهاتف الذكي (Flutter App):
- **واجهة عصرية بالكامل (RTL Dark Mode):** تصميم مستقبلي بألوان نيون وعدادات دائرية متحركة ونصوص عربية واضحة.
- **روابط عميقة ذكية (Deep Linking & App Links):** دعم بروتوكول `ktaab://inspect` و `https://ktaab.local/inspect` لفتح التطبيق تلقائياً بمجرد نقر الرابط في المتصفح والبدء الفوري بالفحص التلقائي.
- **فحص البطارية العميق (Deep Battery Diagnostics):**
  - نسبة شحن البطارية بدقة عبر مؤشر دائري متدرج.
  - صحة البطارية الفعلية من النظام (`Good`, `Overheat`, `Dead`, `Over Voltage`, إلخ).
  - درجة الحرارة الحالية بالمئوية (°C).
  - الجهد الكهربائي بالميلي فولت (mV).
  - تقنية البطارية (Li-ion, Li-poly).
  - مصدر الشحن الحالي (شاحن جداري AC / USB / شاحن لاسلكي / تفريغ الشحن).
  - سعة البطارية الحالية والتصميمية (mAh) وعداد الشحنة (µAh).
- **فحص العتاد والنظام:**
  - الشركة المصنعة، اسم الجهاز، الموديل ورقم البناء (Build ID).
  - إصدار الأندرويد ومستوى تصحيح الأمان (Security Patch).
  - فحص كشف الروت (Root Detection) عبر فحص ملفات `su` و `test-keys`.
  - معمارية المعالج، نوع العتاد، وعدد الأنوية الحقيقية.
  - استهلاك الذاكرة العشوائية (RAM) الكلية والحرة والمستخدمة.
  - مساحة التخزين الإجمالية والمتبقية.
- **الشاشة والمستشعرات والشبكة:**
  - أبعاد الشاشة ومعدل التردد (Refresh Rate Hz: 60/90/120Hz).
  - بث حي لقراءات مستشعرات التسارع (Accelerometer) والدوران (Gyroscope).
  - نوع الاتصال (WiFi / Cellular) وعنوان الـ IP المحلي للجهاز.
- **إرسال ومزامنة التقارير تلقائياً:** فور إتمام الفحص يُرسل تقرير JSON كامل بضغطة زر أو تلقائياً إلى السيرفر.

### 2. السيرفر ولوحة التحكم (Node.js + Express Backend):
- **قاعدة بيانات SQLite محلية مدمجة:** حفظ التقارير بسرعة فائقة ودون الحاجة لتنصيب برامج خارجية عبر محرك `node:sqlite` المدمج في Node.js.
- **تحديثات لحظية (Real-time SSE):** استماع مباشر للتقارير الواردة عبر Server-Sent Events دون الحاجة لإعادة تحميل الصفحة.
- **لوحة تحكم تفاعلية للمدير (`/admin`):**
  - بطاقات إحصائيات: إجمالي الأجهزة، متوسط الشحن، متوسط الحرارة، وتنبيهات الروت.
  - جدول حي يعرض الأجهزة المتصلة مع مؤشرات ملونة للبطارية والحرارة.
  - نافذة منبثقة تفاعلية (Modal Drawer) لعرض الفحص الشامل لأي جهاز.
  - إمكانية تصفية وبحث لحظي وتصدير السجلات بصيغة JSON.
- **صفحة الهبوط الذكية (`/`):**
  - فحص سريع مباشر عبر المتصفح (Web APIs: البطارية، الأنوية، الذاكرة، الشاشة).
  - محاولة توجيه تلقائية لفتح تطبيق الهاتف المثبت.
  - زر تحميل ملف الـ APK.

## 🚀 طريقة التشغيل (Quick Start)

### 1. تشغيل السيرفر الخلفي (Backend Server):

1. افتح منفذ الأوامر في مجلد السيرفر:
```bash
cd backend
npm install
npm start
```
2. لتشغيل الاختبارات التلقائية والتأكد من سلامة قاعدة البيانات ونقاط النهاية:
```bash
npm test
```
3. افتح المتصفح على الروابط التالية:
   - **صفحة الهبوط وفحص المتصفح:** `http://localhost:3000/`
   - **لوحة تحكم المدير المباشرة:** `http://localhost:3000/admin`
   - **رابط التوجيه العميق للتطبيق:** `http://localhost:3000/inspect`

---

### 2. تشغيل تطبيق الهاتف (Flutter App):

1. انتقل لمجلد التطبيق:
```bash
cd ktaab_app
flutter pub get
```
2. تشغيل التطبيق على الهاتف أو المحاكي:
```bash
flutter run
```

> **ملاحظة للربط بين الهاتف والسيرفر:**
> - إذا كنت تستخدم محاكي الأندرويد الافتراضي (Android Emulator)، عنوان السيرفر التلقائي هو: `http://10.0.2.2:3000`.
> - إذا كنت تقوم بالتجربة على هاتف حقيقي عبر الـ Wi-Fi، افتح أيقونة الإعدادات ⚙️ في أعلى شاشة التطبيق وأدخل عنوان الـ IP الخاص بجهاز الكمبيوتر (مثلاً: `http://192.168.1.100:3000`).
